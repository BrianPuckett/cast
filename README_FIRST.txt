ANDY KOH — TAKING THE LONG WAY — GITHUB PAGES SHOWCASE

1. Unzip this folder.
2. Upload index.html and the entire images/ folder to the ROOT of your GitHub Pages repository.
3. In repository Settings > Pages, publish from the desired branch and root folder.
4. All image paths are relative (images/filename.webp), so this works under /cast/ or another project path.
5. The site is static. No build tools, hosting accounts, or GitHub Actions needed.
6. REVIEW WITH ANDY BEFORE PUBLICATION. Confirm permission for photographs, album packaging, and biographical copy.
7. IMPORTANT: The Google Drive folder also contained handwritten lyric-note PDFs and a private voice memo. Those are NOT included because they may be exclusive FanVault rewards. Do not upload those files to a public repository.
8. The supplied original JPGs have been resized/converted to WebP for quick page loads.
9. Album information and credits are based on public press releases. The site is an artist-review concept, not an official artist-approved release.
10. The FanVault Drop link is already wired into the page.
