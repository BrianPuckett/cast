ANDY KOH — TAKING THE LONG WAY — GITHUB PAGES SHOWCASE

1. Unzip this folder.
2. Upload index.html and the entire images/ folder to the ROOT of your GitHub Pages repository.
3. In repository Settings > Pages, publish from the desired branch and root folder.
4. All image paths are relative (images/filename.webp), so this works under /cast/ or another project path.
5. The site is static. No build tools, hosting accounts, or GitHub Actions needed.
6. The supplied original JPGs have been resized/converted to WebP for quick page loads.
7. The FanVault Drop link is already wired into the page.
